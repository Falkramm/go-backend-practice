# Interview — сохранённый учебный черновик

Отдельная тренировка HTTP-обработчиков каталога и заказов на Go с PostgreSQL. Здесь сохранён промежуточный снимок исходников от 16 ноября 2026 года.

## Состояние

- В `catalog/handler.go` определены модели категорий и товаров, входные данные для создания и PATCH, конструктор обработчика.
- Методы `RegisterRoutes` и `Create` пока пустые.
- `main.go` содержит настройку подключения к PostgreSQL, таймауты HTTP-сервера и graceful shutdown.
- `main.go` импортирует `example.com/go-interview/orders`. Каталог `orders` в сохранившемся снимке отсутствует.
- SQL-схема и описание задания в исходном каталоге были пустыми. Тесты отсутствуют.

Для запуска законченного примера CRUD с условиями задания и тестами откройте [пример сервиса заметок](../../go-practice/examples/d01_notes/README.md). Остальные упражнения находятся в [блоке CRUD](../../go-practice/04_crud/).

## Проверка снимка

Из этого каталога выполнялась проверка компиляции без запуска тестов.

```sh
go test -run '^$' -timeout=20s ./...
```

Основной пакет завершился ошибкой из-за отсутствующего пакета заказов.

```text
main.go:17:2: no required module provides package example.com/go-interview/orders
```

Пакет `catalog` компилируется и сообщает `[no test files]`. Подключение к PostgreSQL и работа HTTP-обработчиков для этого снимка не проверены.

## Локальный launcher PostgreSQL

`psql.command` предполагает установленный `psql` и заранее подготовленные учебные базы. Параметры подключения зафиксированы в скрипте.

| Параметр | Значение |
| --- | --- |
| Адрес | `127.0.0.1:15432` |
| Пользователь | `student` |
| База каталога | `go_interview_catalog` |
| База заказов | `go_interview_orders` |
| SSL | `sslmode=disable` для локальной учебной БД |

```sh
./psql.command
./psql.command catalog
./psql.command orders
./psql.command catalog -c '\dt'
```

Первый необязательный аргумент выбирает `catalog` или `orders`. Остальные аргументы передаются `psql`. Пароль в скрипте отсутствует.

`requests.http` содержит сохранённые примеры запросов к локальному серверу. Их выполнение требует реализованных обработчиков и подготовленной БД.
