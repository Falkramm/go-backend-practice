# GO-C02 · Producer/consumer с context и закрытием канала

Реализация прошла тесты и проверку `-race` 16 ноября 2026 года.

Производитель отправляет числа 1…N в канал, потребитель считает сумму. Поддержать общий context и корректное закрытие канала владельцем отправки.

Проверить полный проход с суммой N*(N+1)/2, пустой ввод, отмену во время заблокированной отправки и ожидания получения. После отмены обе горутины завершаются в пределах тестового таймаута.

## Контракт

- `Produce(ctx context.Context, n int, out chan<- int) error` синхронно отправляет числа `1…n` и закрывает `out` при любом возврате. Для `n <= 0` последовательность пустая. Успех возвращает `nil`, отмена — ошибку, распознаваемую через `errors.Is(err, ctx.Err())`.
- `Consume(ctx context.Context, in <-chan int) (int, error)` суммирует полученные значения до закрытия `in` и возвращает сумму с `nil`. При отмене возвращает сумму уже полученных значений и ошибку, распознаваемую через `errors.Is(err, ctx.Err())`.

Заранее отменённый context даёт ошибку для обеих функций, включая пустой проход и уже закрытый вход. Передавай ненулевой context и инициализированные каналы.

## Работа с готовыми тестами

Реализация находится в `exercise.go`, проверки — в `exercise_test.go`.

Тесты используют реальные каналы, сигналы первого обмена и таймаут завершения в две секунды. В сценарии отмены `Produce` тест сначала ждёт возврата функции, затем проверяет закрытие выходного канала. В сценарии отмены `Consume` вход остаётся открытым до возврата функции.

Команды выполняются из этой папки.

```sh
go test -timeout=30s -v .
go test -timeout=30s -race -count=1 .
```
