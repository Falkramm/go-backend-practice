# GO-C01 · Чередовать две горутины через каналы

Реализация прошла тесты и проверку `-race` 16 ноября 2026 года.

Две горутины по очереди формируют последовательность 1…N. Нечётные значения выдаёт первая, чётные — вторая. Координация через каналы.

## Сигнатура

```go
func Alternate(n int) []int
```

Функция возвращает последовательность. Например, `Alternate(6)` возвращает `[1, 2, 3, 4, 5, 6]`. При `n <= 0` результат пустой, `nil` допустим. Обе горутины завершаются до возврата функции.

Проверить N=0, N=1, чётное и нечётное N. Результат должен точно совпасть с 1…N, каждая горутина должна завершиться. Повторить запуск много раз.

## Проверки

Синхронизацию тестов строить на управляемых сигналах готовности и явных таймаутах. Для сценариев со временем заранее определить способ управления временными точками. Завершение запущенных горутин проверять наблюдаемыми результатами.

Команды выполняются из этой папки.

```sh
go test -timeout=30s -v .
go test -timeout=30s -race -count=1 .
```
