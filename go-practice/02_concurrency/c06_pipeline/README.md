# GO-C06 · Pipeline — три стадии с fan-out/fan-in

Реализация прошла тесты и проверку `-race` 16 ноября 2026 года.

API упражнения

    SumSquares(ctx context.Context, input <-chan string, workers int) (int, error)

Поток проходит три стадии — строки, разбор целых чисел несколькими работниками, сумма квадратов. Стадии соединены каналами и используют общий context.

- Успех возвращает точную сумму и nil, пустой закрытый вход — 0 и nil.
- workers должен быть положительным.
- Ошибка strconv.Atoi возвращает 0 и сохраняет исходную причину для errors.Is/As.
- Отмена возвращает 0 и ошибку context. Незакрытый и небуферизованный вход поддерживает отмену.
- Возврат происходит после завершения внутренних стадий.

Готовые тесты проверяют суммы, ошибки, вход без буфера и отмену после обмена. Ограничение числа внутренних работников, топология стадий и завершение каждой внутренней горутины дополнительно проверяются при ревью реализации.

Запусти проверки из этой папки

    go test -timeout=30s -v .
    go test -timeout=30s -race -count=1 .
