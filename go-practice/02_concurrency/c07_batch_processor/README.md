# GO-C07 · Batch processor — пачка по размеру или таймеру

Реализация прошла тесты и проверку `-race` 16 ноября 2026 года.

API использует внедряемые часы

    Batch(ctx context.Context, input <-chan int, batchSize int, maxWait time.Duration,
        c clock.Clock, handle func(context.Context, []int) error) error

- Положительные batchSize и maxWait обязательны.
- Элементы сохраняют порядок. Полная пачка отправляется сразу, неполная — спустя maxWait от её первого элемента.
- Закрытие входа отправляет непустой остаток и завершает работу успешно.
- Обработчик вызывается последовательно для непустых пачек. Его ошибка останавливает работу и сохраняет исходную причину.
- Отмена передаётся обработчику и возвращается как ошибка context.
- При возврате все созданные таймеры освобождены.

Готовые тесты проверяют размер, остаток, пустой вход, срок от первого элемента, новый срок следующей пачки, ошибки и отмену. Временные сценарии используют internal/testclock, WaitForTimers как барьер и Advance для перехода времени. Реальные часы доступны как clock.Real{}.

Запусти проверки из этой папки

    go test -timeout=30s -v .
    go test -timeout=30s -race -count=1 .
