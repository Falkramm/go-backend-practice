# GO-C03 · Fan-in — объединить несколько каналов

Реализация прошла тесты и проверку `-race` 16 ноября 2026 года.

Merge(ctx, inputs...) объединяет несколько входных каналов в один выходной. Выход закрывается после завершения всех входов. При отмене прекращается пересылка.

Проверить ноль входов, пустые и заранее закрытые входы, разную скорость производителей, медленного получателя и отмену при заблокированной отправке. Каждый входной элемент доставляется ровно один раз при успешном проходе, порядок одного источника сохраняется.

## Контракт

```go
func Merge(ctx context.Context, inputs ...<-chan int) <-chan int
```

Функция возвращает инициализированный выходной канал и пересылает значения из каждого входа сразу по мере их поступления. Для каждого источника сохраняется порядок. При нормальном завершении каждое входное значение появляется ровно один раз, выход закрывается после закрытия всех входов. Ноль входов даёт закрытый пустой выход.

При отмене выход закрывается, допустим уже принятый префикс значений. Передавай ненулевой context и инициализированные входные каналы. Отправители владеют закрытием входов, Merge владеет выходом.

## Работа с готовыми тестами

Реализация находится в `exercise.go`, проверки — в `exercise_test.go`.

```sh
go test -timeout=30s -v .
go test -timeout=30s -race -count=1 .
```

Проверки используют сигналы первого обмена и управляемую задержку чтения. Таймаут в две секунды ограничивает ожидание. Сценарий отмены после первого обмена проверяет закрытие выхода при последующем чтении. Отмену при полностью остановившемся чтении выхода и завершение всех внутренних горутин проверь ревью реализации.
