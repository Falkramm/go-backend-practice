# GO-C08 · Конкурентный счётчик по ключам и snapshot

Реализация прошла тесты и проверку `-race` 16 ноября 2026 года.

Counter имеет рабочее нулевое значение и методы

    Add(key string, delta int)
    Get(key string) int
    Snapshot() map[string]int

Add прибавляет delta, Get отсутствующего ключа возвращает 0. Методы поддерживают одновременные чтения и записи. Snapshot возвращает согласованную независимую map. Изменение снимка сохраняет внутренние данные, последующие Add сохраняют старый снимок.

Готовые тесты проверяют точные суммы после конкурентных операций, разные ключи, отрицательные приращения, отсутствующий ключ и владение snapshot. Состояние снимка проверяется после каждого завершённого Add. Каждый отдельный вызов представляет самостоятельное обновление.

Запусти проверки синхронизации из этой папки

    go test -timeout=30s -v .
    go test -timeout=30s -race -count=1 .
