# GO-H03 · HTTP-клиент — таймауты, отмена и ограничение тела

Задание для самостоятельной работы. В exercise.go и exercise_test.go сохранены заготовки. Реализация и исполняемые тесты отсутствуют.

Для своего клиента явно проверить context deadline, ручную отмену и Client.Timeout. Локальный сервер умеет задерживать заголовки, медленно отдавать тело, возвращать пустое/повреждённое JSON-тело и тело сверх заданного лимита.

Проверить различимую причину отмены через errors.Is там, где она применима, своевременный возврат вызывающему коду и наблюдаемую отмену на сервере. Ответ 204 допустим для Delete, пустой 200 при обязательном JSON считается ошибкой.

Проверки завершать управляемыми каналами и ограниченными таймаутами. Серверные обработчики реагируют на request.Context. После каждого сценария закрывать тела и завершать тестовый сервер.

Критерий готовности — воспроизводимые тесты каждого отказного сценария, переиспользуемый клиент и чистый -race.

## Начало работы

Открой exercise.go и exercise_test.go. Сформулируй ожидаемые запросы и ответы, затем напиши код и проверки по условию.

```sh
go test -timeout=30s -v .
go test -timeout=30s -race -count=1 .
```
