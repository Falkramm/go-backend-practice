# GO-J01 · JSON

Реализация и тесты кодирования с обратным чтением готовы. Для дальнейшей практики добавь проверки пустого email, имён полей и повреждённого JSON.

`User` содержит поля `ID int`, `Name string` и `Email string` с JSON-тегами `id`, `name` и `email,omitempty`.

В `exercise_test.go` самостоятельно вызови `json.Marshal` и `json.Unmarshal` и проверь

- JSON содержит имена полей `id`, `name` и `email`.
- Пустой `Email` исключается из JSON.
- Обратное чтение восстанавливает значения полей.
- Повреждённый JSON возвращает ошибку.

Структура находится в `exercise.go`. Из этой папки запусти

```sh
go test -timeout=30s -v .
```
