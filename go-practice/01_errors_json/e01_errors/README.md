# GO-E01 · Ошибки

Реализация и базовые тесты готовы. Для дальнейшей практики добавь сценарий ошибки преобразования с проверкой `errors.As`.

`ParseAge(input string) (int, error)` преобразует строку через `strconv.Atoi`.

- Неотрицательное число возвращает значение и `nil`.
- Отрицательное число возвращает sentinel `ErrNegativeAge`, созданный через `errors.New`.
- Ошибка преобразования оборачивается через `fmt.Errorf` с `%w`.

В своих тестах или вызовах проверь `"18"`, `"0"`, `"-1"` и `"abc"`. Распознай отрицательное значение через `errors.Is`, а ошибку преобразования через `errors.As` с `*strconv.NumError`.

Код находится в `exercise.go`, проверки — в `exercise_test.go`. Из этой папки запусти

```sh
go test -timeout=30s -v .
```
