# Происхождение материалов

Коллекция собрана 16 ноября 2026 года из личной подготовки Даниила Матуса к Go/backend-собеседованиям.

| Раздел | Источник |
| --- | --- |
| `early-practice` | Сохранившиеся локальные упражнения из прежнего проекта go-interview-prep |
| `go-practice` | Более поздняя практика по ошибкам, JSON, конкурентности, HTTP и CRUD |
| `archive/interview` | Отдельный незавершённый набросок backend-интервью |
| `leetcode` | Go-решения из Accepted-отправок автора в LeetCode, восстановленные через сайт |
| Каталог LeetCode | Названия и ссылки из программы подготовки |

В работе использовался Codex. В материалах есть самостоятельно написанные реализации, подготовленные задания и тесты, а также готовые учебные примеры. Папка `go-practice/examples/d01_notes` содержит готовый пример, подготовленный во время занятий. История отдельных строк исходников в этой сборке не восстанавливалась. Для LeetCode сохранены ссылки на конкретные отправки и их вердикты. Дополнения, необходимые для самостоятельной сборки вне редактора LeetCode, описаны рядом с решениями.

Для публикации добавлена общая навигация, обновлены описания состояния упражнений, убраны личные ссылки на планировщик и локальные настройки редактора. Имена и адреса в отдельных тестовых данных заменены нейтральными примерами. В ранних завершённых модулях применён gofmt. Сохранённые алгоритмы и обработчики показывают состояние учебного кода на момент сборки.

Упражнения сопровождаются действующими тестами там, где они сохранились. Известные ошибки и непроверенные свойства перечислены рядом с соответствующими материалами. [Результаты проверок](verification.md)
