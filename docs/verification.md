Восстановлены все 20 задач основного маршрута, LRU Cache, LFU Cache и Last Stone Weight. Ссылки на Accepted-отправки, их даты и число пройденных тестов указаны рядом с кодом. [Решения](../leetcode/README.md)

Из каталога leetcode выполнены команды самостоятельной сборки и статического анализа.

```sh

Код отформатирован gofmt. Локальные поведенческие тесты для восстановленных отправок в этой сборке отсутствуют, команды выше проверяют сборку и статический анализ.

## PostgreSQL и готовый CRUD

Проверка выполнена на отдельном свежем кластере. Создана база `go_practice_reference` с учебным пользователем `student`. После проверки временный кластер остановлен и удалён.

Команда из `go-practice` для собственной локальной базы

```sh
TEST_DATABASE_URL='postgres://student@127.0.0.1:15432/go_practice_reference?sslmode=disable' \
  python3 examples/d01_notes/check.py
```

Runner копирует учебный D01 во временный каталог, подставляет готовые обработчики, сервер и схему из примера, затем выполняет существующие контракты с race detector и `go vet`. Проверены пакеты `cmd/server`, `handler`, `internal/testdb`. Тесты создают отдельные схемы и удаляют их после выполнения.

Покрыты CRUD, PATCH, ограничения схемы, ошибки БД, отмена запроса, конкурентные изменения и остановка сервера. Дополнительно собран и запущен обычный сервер из cmd/server, через HTTP выполнены POST, GET, список, PUT, PATCH и DELETE. Чтение удалённой заметки вернуло 404. Сервер и второй временный кластер затем остановлены. [Код и запуск](../go-practice/examples/d01_notes/README.md)

## Открытые задания и известные ограничения

| Материал | Сохранённое состояние |
| --- | --- |
| C11 | Методы shutdown ещё возвращают `not implemented`, поведенческие тесты падают |
| H02 | Основные методы написаны. Тесты выявляют принятие `null`, второго JSON-документа и хвостового мусора, неполную проверку base URL и обращения к сети при неположительном ID |
| H03 | Условие и TODO-заготовки. Содержательных тестов пока нет |
| Учебный D01 | Часть обработчиков написана, сервер и схема остались заготовками. Серверные тесты падают |
| Учебный D02 | Частичная реализация категорий. Вызывается отсутствующий `handler.New`, объявлен `NewHandler`, сборка падает |
| Учебный D03 | Частичные транзакционные обработчики. Есть неиспользуемый `err`, сборка падает. Replace, Delete и Confirm остаются заглушками |
| `examples/parallel_get` | `FetchURLs` возвращает `nil`, тестов нет |
| `archive/interview` | Отсутствует импортируемый пакет `orders`, сборка основного пакета падает |

Общий запуск `go test ./...` в `go-practice` отражает эти недоработки и завершается с ошибкой. Для отдельных упражнений команды и требования приведены в их README.

У ранних алгоритмов тоже есть ограничения. `MergeIntervals` теряет точечные интервалы. `GroupAnagrams` использует таблицу на 256 значений и восьмибитные счётчики, что ограничивает символы и длины групп повторений. LRU предполагает положительную ёмкость. Дополнительные ранние черновики описаны в своём разделе. [Ранняя практика](../early-practice/README.md)

Зелёные существующие тесты подтверждают покрытые ими сценарии. Пограничные свойства, перечисленные выше, остаются открытой частью учебной работы.
