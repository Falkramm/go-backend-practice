# День 10 — SQL и транзакции

## Запуск

```bash
psql -d prep -f 00_schema.sql   # пересоздать таблицы с нуля (идемпотентно)
psql -d prep -f 01_tasks.sql    # прогнать свои решения задач
psql -d prep                    # интерактивная сессия
```

Из VS Code: открыть терминал → `psql -d prep` → `\i 01_tasks.sql` (выполнить файл)
или построчно копипастить. Полезное в psql: `\dt` — таблицы, `\d employees` — схема, `\x` — вертикальный вывод, `\q` — выход.

## Аномалии вживую (два терминала!)

Открой ДВА терминала с `psql -d prep` — это транзакции А и Б.
Файлы `02_*` и `03_*` — сценарии: выполняй шаги по очереди,
переключаясь между терминалами, как написано в комментариях.

- `02_lost_update.sql` — потерянное обновление и три способа лечения
- `03_deadlock.sql` — взаимная блокировка и детектор Postgres
