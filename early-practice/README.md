# Ранняя практика Go

Сохранённые упражнения из первого цикла подготовки к Go-собеседованиям. Здесь виден путь от слайсов и строк к конкурентной обработке, транзакциям и HTTP-клиентам. Каждый день с Go-кодом содержит отдельный модуль.

Исходные реализации и тесты перенесены с сохранением поведения. В завершённых модулях применён `gofmt`, команды в комментариях приведены к путям этого репозитория.

## Запуск

Из корня репозитория можно запустить отдельный день.

```sh
cd early-practice/day8
go test -race -count=1 -timeout=15s ./...
```

Все проверенные дни 1–9 запускаются из каталога `early-practice`.

```sh
for day in day1 day2 day3 day4 day5 day6 day7 day8 day9
do
    (cd "$day" && go test -race -count=1 -timeout=15s ./...) || exit 1
done
```

SQL-файлы выполняются в отдельной учебной базе `prep`. Сценарии создания схем пересоздают таблицы, а день 11 генерирует миллион синтетических строк. Инструкции по последовательности выполнения находятся рядом с упражнениями.

## Границы сохранённых решений

- `MergeIntervals` из дня 3 теряет отдельно стоящие интервалы вида `[2, 2]`. Существующие тесты охватывают интервалы положительной длины. [Код](day3/algo.go)
- `GroupAnagrams` из дня 8 использует массив из 256 байтов. Символы с кодом больше 255 приводят к выходу за границы, а 256 повторений одного символа переполняют счётчик. Учебные тесты используют короткие ASCII-строки. [Код](day8/algo.go)
- Конструктор LRU из дня 4 предполагает `capacity >= 1`. [Код](day4/lru/lru.go)
- Dockerfile дня 13 сохранён с исходным образом `golang:1.26`. Его доступность и сборка контейнера при публикации не проверялись. [Dockerfile](day13/app/Dockerfile)

Тесты фиксируют поведение сохранённых упражнений. Более поздние задания по конкурентности, HTTP и CRUD находятся в основном учебном блоке репозитория.
